# 🐍 Python Programming – Week 1 Assignments

Welcome to my **Python Programming – Week 1** repository! This repository contains my Week 1 Python assignments and mini project, focusing on Python fundamentals, functions, loops, conditional statements, and modular programming.

## 📌 About the Repository

The objective of this repository is to practice basic Python programming concepts through practical assignments and a mini project.

### 📚 Assignments Included

**1. Temperature Converter (Celsius ↔ Fahrenheit)**
- Converts Celsius to Fahrenheit.
- Converts Fahrenheit to Celsius.
- Uses separate functions for conversion.

**2. Student Grade Calculator**
- Takes student marks as input.
- Calculates total and average marks.
- Assigns grades based on average marks.

**3. Even/Odd & Prime Number Checker**
- Checks whether a number is even or odd.
- Determines whether a number is prime or not.
- Uses functions and conditional statements.

## 🚀 Mini Project: Simple ATM Simulator

A basic ATM simulation system developed using Python.

**Features:**
- PIN-based user login.
- Check account balance.
- Deposit money.
- Withdraw money.
- Interactive ATM menu.
- Uses separate functions for each operation.

- **Programming Language:** Python 3
